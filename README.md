# MyCustomReader
A PDF, EPUB ecc. reader. It includes a night mode and translation with Google Translate

This software uses TGUI (zlib/png license).
This software uses curl (MIT/X derivative license).
This software uses nlohmann/json (MIT license).

Controls: 
Press X to toggle night mode. Moreover, you can select multiple words: first click with your mouse near the word you want to traslate and then move your mouse for creating a rectangle of selection, finally release your mouse button and you will obtain the translation at the bottom of the ui.
